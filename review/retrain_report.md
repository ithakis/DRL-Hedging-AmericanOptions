# Retrained agents vs the submitted paper (OLD numbers clearly labelled)

All NEW numbers come from the PyTorch D4PG-QR pipeline (branch v2-torch-d4pg) and the driver in `review/retrain/`. OLD numbers are copied from the submitted manuscript and are not reproducible (weights lost). Differences in protocol: NEW selects on separate validation paths and reports on test paths with bootstrap standard errors; NEW Heston prices come from the precomputed table (central 0.5 vol-point vega bump, fixes the vega spikes of the original forward bump); NEW Heston scenario is r = 2%, mu = 3%, lambda_v = 0 (the OLD runs also had lambda_v = 0 in the code); the actor input is scaled (median/IQR), which the old acme agent did through layer norm only.
